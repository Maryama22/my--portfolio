Welcome to my personal portfolio repository! This project is a modern, clean, and fully responsive web application built to showcase my technical skills, projects, and web development journey.

---

## 🌟 Key Features & Interactive Functionality

- **🌓 Dynamic Dark / Light Mode:** A seamlessly integrated theme toggle using JavaScript and CSS Variables that preserves UI clarity.
- **📱 Responsive Layout:** Mobile-first approach using Flexbox and CSS Grid to ensure pixel-perfect rendering across all screen sizes.
- **⚡ Interactive Counter Script:** Dynamic DOM manipulation feature built with vanilla JavaScript.
- **📩 Interactive Contact Form:** User-friendly contact interface with instant input validation and feedback response.
- **🤖 Automated CI Workflow:** Integrated GitHub Actions workflow to run automated push and pull-request validation checks.
